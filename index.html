Meet HTML, CSS, JavaScript, and Tailwind

Pengembangan website modern dibangun di atas tiga pilar utama. HTML sebagai struktur, CSS sebagai tampilan, dan Javascript sebagai interaksi. Ditambah dengan Tailwind CSS, proses styling menjadi lebih cepat dan efisien. Berikut adalah peran masing-masing:

HTML (HyperText Markup Language)

HTML atau Hypertext Markup Language adalah bahasa pemrograman pertama yang harus dipahami oleh setiap pengembang web. HTML merupakan tulang punggung dari semua halaman web yang kita lihat. Ini adalah bahasa yang digunakan untuk membangun struktur dasar halaman web, mengatur elemen-elemen, dan menghubungkan mereka satu sama lain. HTML bekerja dengan menggunakan tag (penanda) yang diletakkan di dalam tanda '<' dan '>'.Tugas utamanya adalah memberi struktur pada konten. HTML mendefinisikan elemen-elemen seperti judul, paragraf, gambar, dan link yang dilihat pengguna.


Analoginya : HTML adalah kerangka manusia seperti tulang/ tengkorak yang menentukan tata letak dasar.

CSS (Cascading Style Sheets)

CSS, atau Cascading Style Sheets, adalah bahasa yang digunakan untuk mengatur tampilan atau gaya suatu halaman web yang telah dibangun menggunakan HTML. Dengan CSS, pengembang dapat mengontrol warna, ukuran, tata letak, dan elemen visual lainnya pada halaman. Jika HTML bertanggung jawab atas struktur, maka CSS atau Cascading Style Sheets bertanggung jawab atas tampilan visual dari halaman web. Dengan CSS, Anda dapat mengendalikan segala aspek dari warna, jenis font, tata letak, hingga efek transisi pada elemen-elemen yang ada dalam halaman web. Keuntungan utama dari penggunaan CSS adalah kemampuannya untuk memisahkan tampilan dari struktur, yang memungkinkan perubahan tampilan yang konsisten tanpa harus merubah kode HTML.


Analogi : CSS adalah kulit yang melapisi tengkorak/ tulang, pakaian, ataupun riasan pada manusia

Javascript (JS)

JavaScript adalah bahasa pemrograman yang digunakan untuk memberikan interaktivitas pada halaman web. Dengan JavaScript, kamu dapat mengontrol perilaku halaman, mengambil dan memanipulasi data, serta merespons interaksi pengguna. Ketika tiba pada interaktivitas dan fungsionalitas dinamis, JavaScript adalah bahasa pemrograman yang menjadi pilihan utama. JavaScript memberikan kemampuan kepada pengembang web untuk membuat efek animasi, validasi formulir, dan merespons tindakan pengguna secara real-time. Bahkan, halaman web yang penuh dengan interaksi seperti Google Maps atau platform media sosial, sangat mengandalkan JavaScript.

Bahasa pemrograman ini memungkinkan kamu mengontrol perilaku elemen-elemen di halaman web secara dinamis. Kamu bisa mengubah isi elemen, menambahkan atau menghapus elemen, dan bahkan mengambil data dari server tanpa harus melakukan pembaruan halaman. Ini semua bisa terjadi karena JavaScript dijalankan di sisi klien (di browser pengguna). Misalnya, kamu dapat menggunakan JavaScript untuk membuat kotak pesan muncul saat pengguna mengklik tombol, atau mengubah tampilan gambar saat pengguna meletakkan kursor di atasnya. Dalam beberapa kasus, JavaScript juga digunakan untuk berkomunikasi dengan server dan memperbarui data pada halaman tanpa perlu me-reload seluruh halaman.


Analogi : Javascript adalah otak dan sistem saraf pada manusia

Tailwind CSS (Framework)

Tailwind adalah sebuah utility-first CSS framework yang memungkinkan pengembang untuk membangun desain yang kompleks dengan mudah. Tidak seperti framework CSS lainnya yang menyediakan komponen siap pakai, Tailwind memberikan utility classes yang dapat digunakan untuk menyesuaikan tampilan elemen HTML dengan cepat.

Tailwind menawarkan banyak keuntungan yang membuatnya populer di kalangan pengembang web. Pertama, Tailwind sangat fleksibel. Anda bisa mengatur setiap detail dari elemen user interface (UI) tanpa harus menulis CSS custom. Kedua, Tailwind mempercepat proses pengembangan karena Anda tidak perlu keluar dari HTML untuk menulis style. Ketiga, Tailwind memungkinkan penggunaan desain konsisten di seluruh proyek karena semua style diatur melalui utility classes.


Kelebihan: Pengembangan sangat cepat, mengutamakan konsistensi, dan menghasilkan kode CSS yang lebih ramping (jika dikonfigurasi dengan baik).

Steps to Create a Website

1

Design untuk User Interface (UI/UX)

Tentukan tujuan website dengan cara membuat design ui nya terlebih dahulu. Kamu bisa menggunakan figma untuk membangun design awal website ataupun design melalui platform lain

2

Menyiapkan Peralatan Coding

Siapkan platform untuk text editor (seperti VS Code) untuk menulis code seperti html, css, dan javascript dan Web Browser (seperti Chrome) untuk melihat hasilnya.

3

Membangun Struktur dengan HTML

Buat file `index.html`. Mulailah dengan membangun HTML menggunakan tag-tag HTML dengan judul, paragraf, dan gambar untuk membentuk struktur halaman.

4

Menerapkan Gaya dengan CSS

Selanjutnya, buatlah file `style.css` untuk menghias kerangka tersebut menggunakan CSS. Atur warna, font, dan tata letak agar terlihat lebih indah.

5

Menambah Interaktivitas dengan JavaScript

Buat file `script.js` untuk menambahkan fitur interaktif, seperti tombol yang bisa diklik atau animasi yang bergerak.

6

Mempublikasikan ke Web

Unggah semua file-mu ke layanan hosting (seperti vercel) agar website bisa diakses oleh semua orang..
